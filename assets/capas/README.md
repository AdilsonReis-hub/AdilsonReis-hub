# Capas e imagens do Jiji Hub

Guarde nesta pasta as capas dos jogos e outras imagens usadas pelo site.

- Use nomes simples, de preferência sem espaços ou acentos.
- Atualize o campo `cover_url` em `games.json` com o caminho relativo, por exemplo: `assets/capas/darkwood.jpg`.
- Formatos recomendados: JPG, PNG ou WebP.
